# 智能巡检小车

基于 `STM32F407ZGT6` 与 `OpenMV` 的智能巡检小车工程。项目使用 STM32 标准外设库开发，集成红外循迹、编码器测速、PID 闭环控制、姿态角辅助判断、OpenMV 目标识别和 SYN6658 语音播报等模块。

当前工程的主要运行入口为 `App/main.c`，任务 1 的主要逻辑位于 `App/task1.c`。任务 2、任务 3、任务 4 已预留接口，后续可在现有任务调度框架上继续扩展。

## 功能特性

- 5 路红外传感器巡线，支持基于偏差的循迹控制。
- 左右编码器测速，使用 TIM6 周期中断执行速度 PID。
- 支持编码器脉冲累计与姿态角辅助判断，用于直线路段和转弯阶段控制。
- OpenMV 常在线识别目标，并通过串口主动向 STM32 上报识别结果。
- SYN6658 语音模块用于上电、任务切换和运行状态播报。
- 通过 `PA15` 按键完成任务选择，短按切换任务，长按进入任务。

## 编译方式

本工程不是 CubeMX/HAL 工程，使用 STM32 标准外设库。

1. 使用 Keil uVision 打开 `Project/STM32F407.uvprojx`。
2. 选择目标 `STM32F407`。
3. 编译工程并下载到 STM32F407ZGT6 开发板。
4. 将 `OpenMV/main.py` 和模型文件部署到 OpenMV。

如果本机已配置 Keil 命令行工具，也可以使用：

```powershell
UV4.exe -b Project\STM32F407.uvprojx -t STM32F407
```

## 运行流程

### 1. 上电初始化

系统上电后依次初始化 PWM、电机、编码器、TIM6、USART1/2/3、红外传感器、姿态模块、语音模块、蜂鸣器和按键。初始化完成后语音播报上电状态，并通过蜂鸣器进行提示。

### 2. 任务选择

`PA15` 按键用于任务选择：

- 短按：在任务 1、任务 2、任务 3、任务 4 之间循环切换。
- 长按：进入当前选中的任务。

### 3. 任务执行

当前主要实现的是任务 1。任务 1 进入后默认从 A 点开始，直线路段通过编码器累计脉冲判断行驶距离，转弯阶段结合姿态角进行阶段判断，基础循迹由 5 路红外传感器与 PID 控制完成。

## OpenMV 通信协议

OpenMV 采用常在线识别模式，识别到目标后主动通过 USART1 上报 8 字节数据帧。STM32 侧只负责接收和解析，不再向 OpenMV 发送触发命令。

### 数据帧格式

| 字节 | 内容 | 说明 |
| --- | --- | --- |
| 0 | `0xBB` | 帧头 |
| 1 | `ID` | 物体 ID |
| 2 | `Xh` | X 坐标高字节 |
| 3 | `Xl` | X 坐标低字节 |
| 4 | `Yh` | Y 坐标高字节 |
| 5 | `Yl` | Y 坐标低字节 |
| 6 | `CHK` | 校验和 |
| 7 | `0x55` | 帧尾 |

### 目标 ID

| ID | 目标 |
| --- | --- |
| `0x01` | 打火机 |
| `0x02` | 剪刀 |
| `0x03` | 锤子 |
